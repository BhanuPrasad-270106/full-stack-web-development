1. Difference Between Functions and Classes

Feature Function Class
Purpose Used to perform a specific task. Used as a blueprint for creating objects.
Syntax function add() { } class Student { }
Object Creation Usually performs an operation or returns a value. Objects are created using new.
Properties Does not normally define object properties. Can define common properties for objects.
Methods Functions are used separately. Methods can be defined inside the class.
